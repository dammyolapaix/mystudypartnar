# An unfinished Attempt is kept

An Attempt is stored before it is finished, so a refresh or an interruption resumes the same sitting. A Practice stores a Selection when its Question is submitted. A Test stores a Selection when it is made. Keeping only finished Attempts would make a Score easier to store, and it would drop a Test the Student had already answered. Resume is the point of storing the sitting. A Set has at most one Attempt without a Score, so a second sitting waits until that one is finished.
